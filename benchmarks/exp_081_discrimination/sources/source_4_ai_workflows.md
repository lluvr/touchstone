# Source 4: Stack Overflow Developer Survey 2025 — AI Section

**Report:** Stack Overflow 2025 Developer Survey
**Publisher:** Stack Overflow
**Sample:** Large-scale developer survey (exact N not stated for AI section)
**URL:** survey.stackoverflow.co/2025/ai/

---

## Usage & Adoption
- 84% of respondents use or plan to use AI tools (up from 76% in 2024)
- 51% of professional developers use AI tools daily
- 55.5% of early career developers use daily
- 39.5% of those learning to code use daily

## Sentiment Trends
- 60% positive sentiment toward AI tools in 2025 (DOWN from 70%+ in 2023-2024)
- 61% favorable among professionals
- 53% favorable among those learning to code
- Sentiment declining despite increasing usage — adoption ≠ satisfaction

## Trust & Accuracy (THE KEY DATA)
- 46% actively distrust AI tool accuracy
- 33% trust AI tool accuracy
- Only 3% "highly trust" output
- Experienced developers: LOWEST trust (2.6% highly trust)
- Experienced developers: HIGHEST distrust (20% highly distrust)
- Trust dropped from 40% to 29% year-over-year (per EVALUATION_REDESIGN citation)

## Complex Task Capability
- 29% believe AI tools struggle with complex tasks (down from 35% in 2024)
- Only 4.4% rate tools "very well" at complex tasks
- 25.2% rate tools "good, but not great"
- 39.6% rate tools poorly or very poorly

## Debugging & Productivity
- 45% report debugging AI-generated code is time-consuming
- 66% frustrated with "almost right, but not quite" solutions
- 20% report reduced confidence in own problem-solving

## Deployment Resistance
- 76% don't plan to use AI for deployment/monitoring
- 69% don't plan to use AI for project planning
- 58.7% don't plan to use AI for code review/commits
- Strong boundary: AI for generation yes, AI for critical decisions no

## AI Agents
- 52% don't use agents or use simpler AI tools
- 38% have no plans to adopt agents
- 30.9% use agents daily or weekly
- Among agent USERS: 69% report increased productivity, 70% reduced time on specific tasks
- Only 17% report improved team collaboration from agents

## Vibe Coding
- 72% are NOT vibe coding
- Only 14.7% actively participate
- 5.3% emphatically reject it

## Human-AI Future
- 75.3% would ask humans when distrusting AI answers
- 61.7% cite ethical/security concerns
- 61.3% want full understanding despite AI capability
- Only 4.3% believe they won't need human help

## Agent Tool Preferences
- ChatGPT: 81.7% (out-of-box)
- GitHub Copilot: 67.9%
- Ollama: 51.1% (orchestration)
- LangChain: 32.9%

## Agent Concerns
- 87% concerned about accuracy
- 81% concerned about security/privacy

---

**Key tension:** Usage is near-universal (84%) and growing, but trust is DECLINING (60% sentiment, down from 70%+). Experienced developers trust LEAST (2.6% high trust). The debugging overhead ("almost right but not quite" at 66%) and deployment resistance (76%) reveal a fundamental gap: AI accelerates generation but creates new verification costs. The trust-usage divergence is the central finding — developers use tools they don't trust because the generation speed benefit outweighs the verification cost for certain tasks, but not for critical ones.
