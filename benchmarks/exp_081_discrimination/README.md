# EXP-081 adversarial discrimination benchmark

Internal regression benchmark for the composed `quality_profile.gap` signal:
does the system discriminate faithful from embellished AI outputs against
the same source material? The corpus, expected metrics, and reference
detector were all authored by this project; this is a regression baseline
on a single-vendor corpus, not an external replication.

## Methodology

12 documents generated by xAI `grok-4-1-fast` at temperature > 0 (single
vendor; cross-vendor generalization is open work):

| Topic | Faithful | Embellished |
|---|---|---|
| Remote work (Owl Labs survey) | 2 | 2 |
| Communication (workplace research) | 2 | 2 |
| AI workflows (productivity research) | 2 | 2 |

The same prompt was given to the same model for both conditions, with
the only variation being the system instruction:

- **Faithful**: ground every claim in the provided source; cite no
  external statistics or research.
- **Embellished**: extend the analysis with additional research
  findings, citations, and statistics from your training data.

Both conditions produce ~1,000-word analytical documents. The Touchstone
`quality_profile.gap` signal should discriminate the two by detecting the
ungrounded numbers introduced in the embellished condition.

Note: the embellished instruction names exactly the textual features
(external citations, statistics from training data, forward references)
that Layers 4, 5, and 11 detect. The d statistic measures the system
catching what the instruction tells the generator to add. The effect is
real on this corpus and meaningful as a regression signal; it is not a
construct-validity claim against externally curated faithfulness corpora.

## Reference detector baseline (`detector_v031`)

The expected per-document metrics recorded in `ground_truth.json` were
produced by an earlier internal detector (`detector_v031`):

| Metric | Faithful (N=6) | Embellished (N=6) |
|---|---|---|
| Mean gap | -0.443 | +0.169 |
| SD gap | 0.111 | 0.114 |
| Cohen's d | **-5.43** (CI [-9.077, -4.681]) | |

The detector_v031 numbers are the baseline that the Touchstone
implementation is expected to track to within the MAE bands below;
they are not an independent ground truth.

## Touchstone reproduction (2026-05-12 baseline)

| Metric | Faithful | Embellished | Touchstone | detector_v031 |
|---|---|---|---|---|
| Mean gap | -0.4377 | +0.1585 | - | - |
| **Cohen's d** | | | **-5.238** | -5.43 |
| **Hedges' g** (small-N corrected) | | | **-4.835** | - |
| **95% bootstrap CI on Cohen's d** | | | **[-8.926, -4.498]** | [-9.077, -4.681] |
| Gap direction agreement | | | **100% (12/12)** | - |
| MAE vs detector_v031 | unsourced_rate | gap | substance | presentation |
| | 0.014 | 0.0097 | 0.0095 | 0.0 |

Hedges' g applies the standard small-N correction (1 - 3 / (4 * N - 9))
to Cohen's d; at N=12 the correction shrinks |d| by ~7.7%. The 95%
bootstrap CI is computed via stratified percentile bootstrap (each group
resampled with replacement to its original size, 2000 resamples, fixed
seed=0 for snapshot pinning). The wide CI (~4.4 units) is honest about
the effect's magnitude uncertainty at N=6/6; the sign is stable across
all resamples.

Touchstone tracks the recorded detector_v031 numbers to within MAE 0.014
across every per-document metric. This is an internal regression baseline:
it asserts the current implementation has not drifted from the recorded
detector behavior. It does not assert that the construct generalizes
beyond this corpus.

## What this benchmark does and does not establish

Establishes (with corpus-bound caveats):
- Layers 4, 5, 7, 8 (composed via Layer 10) discriminate this specific
  faithful-vs-embellished construct on this 12-document single-vendor
  corpus.
- Cohen's d = -5.238 reproduces to within 0.2 of the recorded
  detector_v031 baseline on the same corpus.
- Per-document gap direction matches detector_v031 on 12/12.

Does not establish:
- Construct generalization to externally curated faithfulness corpora
  (TRUE, LLM-AggreFact, HaluBench, HaluEval).
- Cross-vendor generalization at fast tier; corpus is single-vendor.
- Generalization to flagship-tier models; corpus is fast-tier only.
- Head-to-head comparison against AlignScore, MiniCheck, HHEM 2.1,
  SelfCheckGPT, G-Eval, or other published faithfulness metrics.
- Statistical reliability at small N: Hedges' g (-4.835) and the
  bootstrap CI ([-8.926, -4.498]) are reported in the table above;
  they quantify uncertainty within this corpus. They do not address
  generalization to other corpora, which remains the open work.

## Files

- `ground_truth.json` - machine-readable corpus index with the
  project-authored per-doc expected metrics (recorded by an earlier
  internal detector `detector_v031`; not external ground truth)
- `sources/` - 3 source documents (Owl Labs hybrid work survey,
  communication research, AI workflows research)
- `outputs/` - 12 model outputs (3 topics × 2 conditions × 2 versions)
- `run.py` - benchmark runner;
  `python -m benchmarks.exp_081_discrimination.run`
- `results/` - dated JSON snapshots
